## Gabriel Cavalcante

**'Analista de dados'**

Olá, meu nome é Gabriel Cavalcante. Tenho 22 anos de idade e natural de São Paulo. Estou no momento cursando Engenharia da Computação na Universidade São Francisco e fazendo iniciação científica em ciência de dados e desenvolvimento web. A área da computação é de meu interesse desde jovem, especialmente por influência do meu pai, que é desenvolvedor de software há mais de 40 anos. Estou entrando nessa área pois vi em vários sites na internet, matérias de jornais e entrevistas, dizendo que a área de computação e dados é a área mais promissora dos últimos anos, então eu entrei de cabeça no desafio.

Especialidades:
- Análise de dados
- Conhecimento em Python avançado
- Plotagem de gráficos
- Limpeza e padronização de dados
- Análise de tendências e relações nos dados
- Alto conhecimento em matemática
- Inglês avançado
